隐私政策

书签清理助手（Bookmark Cleaner Assistant）· 最后更新：2026-09-21

一句话总结：本扩展不收集、不存储、不传输、不出售你的任何个人数据。所有书签数据仅在你的浏览器本地处理。

1. 我们收集哪些数据？

不收集。本扩展没有账号系统、没有分析统计、没有遥测、没有广告、没有第三方代码。

2. 数据在哪里处理？

全部在你的设备本地。书签树、扫描结果、回收站、操作历史、设置均保存在浏览器扩展的本地存储（chrome.storage.local）中，不会上传到任何服务器。

3. 哪些操作会访问网络？

操作网络行为说明
链接检测（扫描） 访问你书签中的网址 用于判断链接是否失效 / 是否搬家。请求不携带你的账号信息（不含 Cookie 凭证上传），仅为判断可达性
Wayback 查存档 将书签 URL 发送至 archive.org 仅当你主动点击「查存档」时发生
其他所有功能 无网络请求 清理、归档、画像、时光机、导出、回收站均为纯本地操作

4. 权限用途

权限用途申请方式
bookmarks读取与整理书签（核心功能）安装时
storage / unlimitedStorage本地保存设置、回收站、扫描结果安装时
alarms每周自动扫描 / 自动备份的定时器安装时
sidePanel在浏览器侧边栏显示时光机安装时
网站访问（<all_urls>）检测书签链接是否失效 / 搬家按需申请（首次扫描时）
webRequest / webNavigation「浏览器实测」获取链接真实状态码按需申请
history「未访问」检测（本地比对，不上传）按需申请
downloads导出备份 / 分享页 / 长图按需申请

5. 数据分享与出售

不分享、不出售、不用于广告或信用评估。没有任何数据离开你的设备（除上述第 3 条明确列出的链接检测请求外）。

6. 如何删除你的数据？

卸载扩展即删除全部本地数据；也可以在扩展内清空回收站 / 历史 / 扫描结果。

7. 联系我们

8. 政策变更

如有变更，将更新本页面并注明日期。

Privacy Policy (English)

Summary: this extension does not collect, store, transmit, or sell any personal data. All bookmark data is processed locally in your browser.

  • No accounts, no analytics, no telemetry, no ads, no third-party code.
  • Bookmarks, scan results, trash, history and settings are stored locally via chrome.storage.local.
  • Network access happens only for: (1) checking whether your bookmarked links are alive or moved; (2) the optional Wayback Machine lookup on archive.org when you click "Check archive".
  • Sensitive permissions (site access, webRequest/webNavigation, history, downloads) are requested on demand, not at install time.
  • Uninstalling the extension deletes all local data.
  • Contact: GitHub Issues or leafgroveco@gmail.com.
